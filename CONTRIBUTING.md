# Contributing to Venturelens

Thank you for contributing to **Venturelens**!

## Development Setup

1. Clone repository:
   ```bash
   git clone https://github.com/dathasaiswaroopgudimella-png/Venturelens.git
   cd Venturelens
   ```

2. Copy `.env.example` to `.env.local` and set required environment keys:
   ```bash
   cp .env.example .env.local
   ```

3. Install dependencies and start local development server:
   ```bash
   npm install
   npm run dev
   ```

4. Run lint and build verification before opening a pull request:
   ```bash
   npm run lint
   npm run build
   ```
